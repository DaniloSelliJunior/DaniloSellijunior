## Featured projects

### [Route Telemetry Converter](https://github.com/DaniloSelliJunior/Route-Telemetry-Converter)

A Python desktop app that converts binary logs from our ESP32 datalogger into **MoTeC i2 (.ld)** and **CSV** files.

- Robust parser: fixed-rate resampling, timestamp rollover, resync after corrupted data, plus a log quality report
- Derived channels and a KPI engine, with session comparison and HTML/PDF reports
- Automated tests with **pytest** and CI on **GitHub Actions**
- **Next:** storing session history in **SQLite**

Built with the help of AI assistants for code, tests and documentation, reviewed and tested by me.

### [warehouse-fifo-db](https://github.com/DaniloSelliJunior/warehouse-fifo-db)

**PostgreSQL** database for warehouse addressing and stock control, with FIFO output and expiry date handling (academic project).

### [Projeto-Filtro-de-Bloom](https://github.com/DaniloSelliJunior/Projeto-Filtro-de-Bloom)

**C++** system for large-scale malware detection: a Bloom filter with double hashing works as a hybrid screening step in front of a linked list, speeding up lookups.
